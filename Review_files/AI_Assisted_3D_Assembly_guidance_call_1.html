Motivation

Problem Statement

🔩

Manual Selection Burden

Engineers manually pick parts during assembly creation — slow, error-prone, and dependent on prior expertise.

🔗

Complex Interdependencies

Assemblies have spatial and functional relationships between components that are difficult to encode by hand.

❓

No Intelligent Assistance

CAD tools lack learning-based intelligence to detect missing parts or suggest the next component contextually.

📉

Standardisation Gap

Inconsistent part choices across designers lead to non-standard assemblies, rework, and increased costs.

Research Gap: No existing CAD tool uses graph-based deep learning to recommend components from partial assemblies without proprietary API dependency.

Solution

Proposed System Overview

  • Graph Representation: CAD assembly → graph. Components = nodes (type, geometry features). Relationships = edges (spatial, mating, hierarchical).
  • GNN Learning: Train on historical assemblies to learn structural patterns from complete graphs.
  • Dual Prediction: (1) Detect missing components — link prediction. (2) Suggest top-K next components for partial assembly.
  • Python-Only Stack: No proprietary CAD API dependency. PyTorch Geometric + NetworkX.
  • Interpretability: Attention weights and GNNExplainer to explain why a component is recommended.

Methodology

Technical Approach

  1. Data Collection: Parse CAD datasets (ABC Dataset / PartNet) into attributed graphs via NetworkX.
  2. Graph Construction: Node features = component type, geometry metadata. Edge features = mate type, constraint.
  3. GNN Architecture: Evaluate GCN → GAT → GraphSAGE. Final model selected by validation metrics.
  4. Training: Supervised with negative sampling. Evaluate on held-out partial assemblies.
  5. Recommendation: Top-K ranking via learned embeddings + cosine similarity scoring.
  6. Explain & Visualise: GNNExplainer + attention maps for decision transparency.

Model

GNN Architectures to Explore

🌐

GCN

Spectral convolution baseline. Aggregates neighbourhood features via normalised adjacency. Strong structural pattern learning.

🎯

GAT

Learns per-edge attention weights. Focuses on most relevant neighbouring parts. Built-in interpretability via attention scores.

📡

GraphSAGE

Inductive via neighbour sampling. Scales to large assemblies. Generalises to unseen component types at inference time.

🔮

Heterogeneous GNN

Multiple node & edge types (fastener, body, joint). Captures richer CAD semantics than homogeneous graphs.

Task Framing — Missing component: link prediction (predict missing edge + node type).  Next component: node generation / ranking over partial subgraph.
