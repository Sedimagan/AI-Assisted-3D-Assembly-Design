AI-Assisted 3D Assembly Design

Predicting, ranking, and generating missing components in CAD assemblies with Graph Neural Networks
Abstract
Modern CAD tools offer no contextual intelligence during assembly creation — engineers rely entirely on experience to notice a part is missing, decide what belongs there, and choose its shape. This project builds a three-phase, GNN-based pipeline that closes that loop end-to-end. A Graph Attention Network encodes each CAD assembly as a graph of solid bodies and real contact edges; a frozen copy of this encoder then feeds three task heads — a LinkPredictor that detects missing components (Phase 1), a NodeRanker that ranks which component type is missing next (Phase 2), and a hybrid retrieval + conditional-VAE shape generator that produces an actual placeable mesh for the missing part (Phase 3). An Octree-based open-surface detector locates the unmated joint on the 3D mesh, and a Gemini-powered agent (AIDA) explains every prediction in engineering language. Implemented entirely in Python with PyTorch Geometric — no proprietary CAD-API dependency.

Evaluation Protocol
True 5-fold cross-validation for Phase 1 & 2 — every graph rotates through the test set exactly once, avoiding the variance-masking seen under a fixed held-out split. Phase 3 evaluated on a held-out leave-one-node-out shape-completion task.
Engineering Rigor
Auto-resume watchdogs recover training from silent swap-pressure kills mid-fold with zero progress loss; a promotion-gate bug that silently ignored AP was found and fixed before any model reached production.

Research Gap Addressed
Existing generative CAD work (BrepGen, SolidGen, CAD-GPT) synthesises geometry from scratch or from a text/sequence prompt — none of them read a partial, real assembly graph and recommend a specific, placeable, retrievable part for the exact open joint, with a plain-language explanation, and without a proprietary CAD-API dependency. That combination is the contribution of this pipeline.
