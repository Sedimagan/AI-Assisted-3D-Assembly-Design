Key Design Decisions

gmsh over cascadio

  • Self-contained ARM wheel on M1 — no compilation
  • OpenCASCADE built-in solid body + surface extraction
  • Subprocess wrapper avoids Streamlit signal-handler thread error

Plotly over stpyvista

  • isolate_styles removed in Streamlit ≥ 1.29 — stpyvista broken
  • Plotly Mesh3d is native Streamlit — no iframe conflicts
  • @st.cache_data on conversion — sidebar changes instant

uv over pip

  • 10–100× faster resolution and install
  • Native M1 ARM wheels auto-selected
  • Used in bootstrap.sh for reproducible setup
No proprietary CAD API. gmsh · PyTorch Geometric · Streamlit · Gemini — fully open-source stack.
