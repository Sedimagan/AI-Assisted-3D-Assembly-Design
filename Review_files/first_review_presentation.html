Algorithms
Parthasarathy Perumal  |  Prof. Sagarika Borah
Graph Attention Network — Veličković et al., 2018

Attention Mechanism

/* attention coefficient */ e_ij = LeakyReLU( aᵀ [Whᵢ ‖ Whⱼ] ) α_ij = softmax_j( e_ij ) /* multi-head aggregation (K heads) */ h'ᵢ = ‖_k σ( Σ_{j∈N(i)} α_ij^k · W^k hⱼ ) /* edge-feature bias (Layer 1 only) */ ẽ_ij = Linear(edge_attr_ij) e_ij ← e_ij + ẽ_ij
  • 4 heads on L1 · 2 heads on L2 · 1 head on L3
  • Edge features injected on L1 only — gradient stability
  • ELU activation · BatchNorm · Dropout 0.2
Link Prediction — Graph Autoencoder
/* MLP decoder */ score(u,v) = MLP( z_u ‖ z_v ) ℒ_link = BCE( σ(score_pos), 1 ) + BCE( σ(score_neg), 0 )
  • Hard negatives: P(u,v) ∝ deg(u)⁰˙⁷⁵ · deg(v)⁰˙⁷⁵
  • 1 positive : 1 negative per batch
Node Ranking — Cosine Similarity
ctx = proj( mean(Z_partial) ) score = cosine_sim( ctx, z_cands )
  • Mean-pooled partial assembly context
  • Scored against full component library
  • Returns top-K ranked candidates

Techniques
Parthasarathy Perumal  |  Prof. Sagarika Borah

① Graph Construction from STEP

  • gmsh + OpenCASCADE extracts solid bodies
  • Shared bounding surfaces → mate edges
  • Fallback: bounding-box proximity
  • Subprocess pattern — avoids signal-handler conflict
gmsh
PyG Data

② Partial-Graph Augmentation

  • Mask 20–40% of edges per assembly
  • Simulates in-progress assembly scenarios
  • RandomLinkSplit — no assembly ID leakage
  • Hard negatives via degree-proportional sampling
RandomLinkSplit
Hard Negatives

③ Dual-Head Shared Encoder

  • Single encoder serves both task heads
  • 38% fewer params vs. two separate encoders
  • Joint training: +0.024 AUC · +0.031 Hit@5
  • One backward pass updates both heads
Multi-task
Parameter-efficient

  • YAML profile → Gemini system_instruction
  • 6 skill domains loaded dynamically
  • explain_prediction · identify_component · suggest_sequence
  • Offline-safe — degrades gracefully without API key
