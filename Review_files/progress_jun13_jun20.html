AI-Assisted 3D Assembly Design

Project Progress Update  ·  June 13 – June 20, 2026  ·  M.Tech Data Science & AI, Sem 4  ·  Parthasarathy Perumal

Phase 1 Goal: Train a Graph Attention Network (GAT) to predict missing components in 3D CAD assemblies via link prediction. Targets: AUC-ROC ≥ 0.85  ·  Avg Precision ≥ 0.82.

What changed this week?

  • Introduced 5-Fold Cross-Validation — more honest performance estimates

Key dataset insight

Fusion360 Gallery is a general-purpose 3D collection — not purpose-built for mechanical assemblies. Categories like SCI-FI, Art, Jewelry add noisy geometry that hurts training. Quality > Quantity. R14's 270 focused graphs outperform R13's 807 noisy ones.

5-Fold CV · Category Filter · Dataset Quality

5-Fold Cross-Validation (13 Jun)

  • Fixed 15% test set — held out across all folds
  • Remaining 85% split by sklearn.KFold(5)
  • Each fold: 4 parts train → 1 part val. Repeat 5×
  • Fresh model + optimiser per fold — no leakage
  • Saves best_fold{n}.pt + best_overall.pt
  • Outputs cv_summary.json (mean±std, per-fold scores)

R15 — Six Model Improvements (P1–P6)

Implemented 20 Jun 2026  ·  Targeting AUC ≥ 0.85  ·  Training now in progress on 270 real graphs

P1
GAT attention heads: [8, 4, 1] Was [4, 2, 1]. More heads in early layers → richer multi-relational attention over assembly contacts. File: config.yaml
P2
18-dim affine-invariant node features (was 16-dim) Replaced rotation-sensitive bbox Δx/Δy/Δz with 5 shape descriptors:
[10] elongation  [11] flatness  [12] aspect x/y  [13] aspect y/z  [14] sphericity
Sphericity = min(1, π^⅓ × (6V)^⅔ / SA) — normalised, rotation-invariant.
P2f
model.py defaults updated to in_dim=18 Both AssemblyGNN.__init__ and build_model() now default to 18. Processed cache data.pt deleted to force rebuild.
P3
Structured synthetic graphs (was random) 3 templates: bolt-bracket, shaft-bearing-housing, mixed.
Geometry-hint-driven realistic features — elongated shafts, compact bolts, hollow bearings.
Filtered: nodes ≥ 4; None graphs dropped. ~500 per run.
P4
Hard negative sampling hard_negative_pairs(z, pos_ei, n_hard) — for each positive-edge source, finds the most cosine-similar non-neighbour node as a hard negative.
Loss = BCE(pos+neg) + 0.3 × BCE(hard negatives). Forces model to learn fine-grained distinctions.
P5
neg_ratio: 0.5 (was 1.0) Halved random negatives per positive edge. Hard negatives from P4 cover the rest — higher-quality signal with less trivial noise.
P6
5-Fold Cross-Validation (already in place) Implemented 13 Jun. R15 inherits all CV infrastructure. Results will report mean±std over 5 folds.
