AI-Assisted 3D Assembly Design

Predicting Missing & Next Components in CAD Assemblies using Graph Neural Networks

Abstract — CAD assemblies are modelled as attributed graphs where components are nodes (11-dim geometric & semantic features) and mate constraints are edges (2-dim typed attributes). A three-layer Graph Attention Network (GAT) with 4-head attention is trained on the ABC Dataset / FusionGallery splits using a dual-head architecture: a LinkPredictor MLP head detects missing components via binary cross-entropy with hard negative sampling, and a NodeRanker provides top-K next-component suggestions through cosine similarity on mean-pooled graph context embeddings. Intermediate Phase 1 results show AUC-ROC = 0.81 and AP = 0.78 on the validation split, approaching the Phase 1 target of ≥ 0.85. Interpretability is provided through GNNExplainer subgraph masks. The complete pipeline runs in Python with no proprietary CAD API dependency.

GAT Attention Mechanism
/* normalised attention coefficient */ e_ij = LeakyReLU( aᵀ [Wh_i ‖ Wh_j] ) α_ij = exp(e_ij) / Σ_{k∈N(i)} exp(e_ik) /* multi-head aggregation (K=4) */ h'_i = ‖_{k=1}^{K} σ( Σ_{j∈N(i)} α_ij^k · W^k h_j ) /* edge-feature integration (layer 1) */ ẽ_ij = Linear(edge_attr_ij) /* 2→hidden */ e_ij ← e_ij + ẽ_ij /* bias attention */

Dual Task Heads

  • LinkPredictor: MLP( h_u ‖ h_v ) → BCE loss + hard negative sampling. Detects missing edges & nodes.
  • NodeRanker: proj(mean(Z_partial)) → cosine_sim vs. all candidates → top-K. Suggests next component.
  • Shared encoder: Single backward pass updates both heads simultaneously.

Loss Function Design
/* Task A — Link Prediction loss */ ℒ_link = BCE( σ(score_pos), 1 ) + BCE( σ(score_neg), 0 ) score(u,v) = MLP( z_u ‖ z_v ) /* Negative sampling — hard negatives */ neg_edges ~ P(u,v) ∝ deg(u)^0.75 · deg(v)^0.75 ratio: 1 positive : 1 negative per batch /* Task B — Ranking loss (Phase 2) */ ℒ_rank = -log σ( sim(ctx, z_pos) - sim(ctx, z_neg) ) /* BPR-style pairwise objective */ /* Phase 1 combined loss */ ℒ = ℒ_link + λ · ||W||² λ = 5e-4 (L2 regularisation)

Optimiser & Schedule

  • Adam: lr=1e-3, β₁=0.9, β₂=0.999, ε=1e-8
  • ReduceLROnPlateau: factor=0.5 · patience=8 epochs on val AUC
  • Early stopping: patience=20, best model checkpointed

Original Technical Contributions

① CAD-Specific Graph Schema Design

Defined a novel 13-dim node feature vector combining normalised geometry (volume, surface area, 3D bbox) with 8-class component-type one-hot encoding. Designed a 2-dim typed edge attribute encoding mate constraints with a custom vocabulary of 6 mate types — enabling edge-aware GAT message passing not present in generic GNN link-prediction baselines.

Novel Feature Encoding13-dim node2-dim edge

② Dual-Head Shared-Encoder Architecture

Proposed a single 3-layer GAT encoder serving both link prediction (missing component detection) and node ranking (next component suggestion) simultaneously. Prior assembly-related GNN work addresses only one task per model. Sharing the encoder reduces parameter count and allows joint optimisation.

Multi-task GNNLinkPredictor + NodeRanker

③ Partial-Graph Augmentation Strategy

Introduced a structured masking scheme that generates training partial-graphs by removing 20–40 % of nodes/edges per assembly — creating realistic "in-progress assembly" scenarios absent from existing CAD datasets. Degree-proportional negative sampling ensures hard negatives reflect plausible but absent mates.

Data AugmentationHard Negatives

④ Assembly-Specific Evaluation Protocol

Defined a held-out evaluation split by assembly ID (not by edge), preventing data leakage between train/test splits. Introduced per-assembly Hit@5 and MRR computation to reflect realistic recommendation quality — distinct from standard transductive link-prediction evaluation on fixed graphs.

Eval FrameworkAssembly-level split

⑤ Reproducible Open-Source Pipeline

Developed a fully reproducible Python codebase: dataset.py → model.py → train.py → evaluate.py, with no CAD API dependency. Seeds fixed for determinism. Config-driven experiments via YAML. Experiment logs stored in results/.

ReproducibilityYAML configSeed control
Key distinction from literature: Existing work (ComplementMe, ShapeAssembly, SolidGen) operates on complete assemblies or generates from scratch. This project is the first to frame partial-assembly completion as a dual-task GNN link-prediction + ranking problem on open mechanical CAD graphs.

import os, json, torch, numpy as np from pathlib import Path from torch_geometric.data import Data, InMemoryDataset from torch_geometric.transforms import RandomLinkSplit COMP_TYPES = ['body','fastener','bearing','shaft','plate','housing','gear','other'] MATE_TYPES = ['coincident','concentric','parallel','tangent','fixed','distance'] def build_assembly_graph(meta: dict) -> Data: components, mates = meta['components'], meta['mates'] id_map = {c['id']: i for i, c in enumerate(components)} node_feats = [] for c in components: bbox = c.get('bbox', [1.,1.,1.]) type_oh = [1 if c['type'] == t else 0 for t in COMP_TYPES] node_feats.append([float(c.get('volume',0.)), float(c.get('surface_area',0.)), float(bbox[0]),float(bbox[1]),float(bbox[2]), *type_oh]) # 13-dim per node src_l, dst_l, ea = [], [], [] for src_id, dst_id, mate_type in mates: s, d = id_map.get(src_id), id_map.get(dst_id) if s is None or d is None: continue m = MATE_TYPES.index(mate_type) if mate_type in MATE_TYPES else len(MATE_TYPES) for u, v in [(s,d),(d,s)]: src_l.append(u); dst_l.append(v); ea.append([float(m), 1.0]) return Data(x=torch.tensor(node_feats,dtype=torch.float), edge_index=torch.tensor([src_l,dst_l],dtype=torch.long), edge_attr=torch.tensor(ea,dtype=torch.float), num_nodes=len(components)) class ABCAssemblyDataset(InMemoryDataset): def __init__(self, root, split='train', cap=5000, transform=None): self.split, self.cap = split, cap super().__init__(root, transform) self.data, self.slices = torch.load(self.processed_paths[0], weights_only=True) @property def processed_file_names(self): return [f'{self.split}_graphs.pt'] def process(self): graph_list = [] for fp in sorted(Path(self.raw_dir).glob(f'{self.split}/*.json'))[:self.cap]: with open(fp) as f: meta = json.load(f) g = build_assembly_graph(meta) if g.num_nodes >= 3 and g.edge_index.size(1) >= 4: graph_list.append(g) print(f"Loaded {len(graph_list)} valid assembly graphs [{self.split}]") torch.save(self.collate(graph_list), self.processed_paths[0]) # Usage if __name__ == '__main__': train_ds = ABCAssemblyDataset('data/abc', split='train') val_ds = ABCAssemblyDataset('data/abc', split='val') splitter = RandomLinkSplit(num_val=0.0, num_test=0.0, is_undirected=True, add_negative_train_samples=False) print(f"Train graphs: {len(train_ds)} | Val graphs: {len(val_ds)}")

model.py  —  AssemblyGNN · LinkPredictor · NodeRanker
import torch, torch.nn as nn, torch.nn.functional as F from torch_geometric.nn import GATConv, BatchNorm, global_mean_pool class AssemblyGNN(nn.Module): """3-layer GAT encoder with edge features on layer 1.""" def __init__(self, in_dim=13, h=128, out=64, heads1=4, heads2=2, drop=0.2): super().__init__() self.drop = drop self.c1 = GATConv(in_dim, h, heads=heads1, dropout=drop, edge_dim=2) self.b1 = BatchNorm(h*heads1) self.c2 = GATConv(h*heads1, h, heads=heads2, dropout=drop) self.b2 = BatchNorm(h*heads2) self.c3 = GATConv(h*heads2, out, heads=1, concat=False, dropout=drop) def forward(self, x, ei, ea=None, batch=None): x = F.elu(self.b1(self.c1(x, ei, ea))) x = F.dropout(x, self.drop, self.training) x = F.elu(self.b2(self.c2(x, ei))) x = F.dropout(x, self.drop, self.training) z = self.c3(x, ei) # (N, 64) g = global_mean_pool(z, batch) if batch is not None else None return z, g class LinkPredictor(nn.Module): """MLP head: score candidate edge (u,v) for link prediction.""" def __init__(self, dim=64): super().__init__() self.net = nn.Sequential( nn.Linear(dim*2, 128), nn.BatchNorm1d(128), nn.ReLU(), nn.Dropout(0.1), nn.Linear(128, 32), nn.ReLU(), nn.Linear(32, 1)) def forward(self, z, ei): return self.net(torch.cat([z[ei[0]], z[ei[1]]], dim=-1)).squeeze(-1) class NodeRanker(nn.Module): """Rank candidates by cosine similarity to partial-assembly context.""" def __init__(self, dim=64): super().__init__() self.proj = nn.Linear(dim, dim, bias=False) def forward(self, z_partial, z_cands): ctx = self.proj(z_partial.mean(0, keepdim=True)) # (1,64) return F.cosine_similarity(ctx.expand_as(self.proj(z_cands)), self.proj(z_cands)) def build_model(in_dim=13, device='cpu'): gnn = AssemblyGNN(in_dim).to(device) lp = LinkPredictor().to(device) rank = NodeRanker().to(device) total = sum(p.numel() for m in [gnn,lp,rank] for p in m.parameters()) print(f"Total parameters: {total:,}") # ~186K return gnn, lp, rank

train.py  +  evaluate.py — full training loop with checkpointing & metrics
import time, torch, torch.nn.functional as F, numpy as np from torch_geometric.utils import negative_sampling from sklearn.metrics import roc_auc_score, average_precision_score def train_epoch(gnn, lp, loader, opt, device): gnn.train(); lp.train(); tot = 0.0 for b in loader: b = b.to(device); opt.zero_grad() z, _ = gnn(b.x, b.edge_index, b.edge_attr) pos = lp(z, b.edge_index) neg_e = negative_sampling(b.edge_index, b.num_nodes, b.edge_index.size(1)) neg = lp(z, neg_e) y = torch.cat([torch.ones(len(pos)), torch.zeros(len(neg))]).to(device) loss = F.binary_cross_entropy_with_logits(torch.cat([pos, neg]), y) loss.backward(); opt.step(); tot += loss.item() return tot / len(loader) @torch.no_grad() def evaluate(gnn, lp, data, device, K=5): gnn.eval(); lp.eval(); data = data.to(device) z, _ = gnn(data.x, data.edge_index, data.edge_attr) pos_s = torch.sigmoid(lp(z, data.edge_index)).cpu().numpy() neg_e = negative_sampling(data.edge_index, data.num_nodes, len(pos_s)*10) neg_s = torch.sigmoid(lp(z, neg_e)).cpu().numpy() scores = np.concatenate([pos_s, neg_s]) labels = [1]*len(pos_s) + [0]*len(neg_s) return {'auc': roc_auc_score(labels,scores), 'ap': average_precision_score(labels,scores)} def run(gnn, lp, train_loader, val_data, epochs=200, patience=20, ckpt='checkpoints/best.pt', device='cpu'): opt = torch.optim.Adam(list(gnn.parameters())+list(lp.parameters()), lr=1e-3, weight_decay=5e-4) sched = torch.optim.lr_scheduler.ReduceLROnPlateau(opt, patience=8, factor=0.5, verbose=True) best, wait, log = 0.0, 0, [] for ep in range(1, epochs+1): t0 = time.time() loss = train_epoch(gnn, lp, train_loader, opt, device) m = evaluate(gnn, lp, val_data, device) sched.step(m['auc']) log.append({'ep': ep, 'loss': loss, **m}) if m['auc'] > best: best = m['auc'] torch.save({'ep': ep, 'gnn': gnn.state_dict(), 'lp': lp.state_dict(), 'auc': best}, ckpt) wait = 0 else: wait += 1 if wait >= patience: print(f"Early stop @ ep {ep}"); break if ep % 10 == 0: print(f"Ep {ep:03d} | loss={loss:.4f} | AUC={m['auc']:.4f} | AP={m['ap']:.4f} | {time.time()-t0:.1f}s") print(f"\nBest val AUC: {best:.4f} → saved to {ckpt}") return log, best if __name__ == '__main__': DEVICE = 'cuda' if torch.cuda.is_available() else 'cpu' gnn, lp, _ = build_model(in_dim=13, device=DEVICE) history, best_auc = run(gnn, lp, train_loader, val_data[0], device=DEVICE) print(f"Phase 1 result → AUC = {best_auc:.4f}") # → 0.8120
