Abstract
This project develops an end-to-end AI pipeline that analyses partial 3D mechanical assemblies supplied as STEP files, constructs graph representations of parts and their mating relationships, and employs a Graph Attention Network (GAT) to detect missing components. A natural-language assistant AIDA, powered by Gemini 2.5 Flash, explains assembly structure and suggests corrective actions. The system is delivered as an interactive web application combining a FastAPI backend with a Streamlit 3D-viewer frontend.

Input Processing

STEP File → Geometry

  • STEP files as assembly input
  • gmsh + OpenCASCADE for B-rep solid parsing
  • Mesh generation and solid body extraction
  • Synthetic graph fallback for testing
Graph Construction

Assembly Graph Features

  • Node (13-dim): part-type one-hot (8) + volume + surface area + bounding-box Δx / Δy / Δz
  • Edge (2-dim): mate-type encoding + contact weight
GNN Model

AssemblyGNN — Graph Attention Network

  • 3-layer GAT with 8 attention heads per layer
  • 64-dimensional node embeddings (hidden = 128)
  • Dropout = 0.1 for regularisation
  • Adam + ReduceLROnPlateau scheduler
Prediction & AI Explanation

Link Predictor + AIDA Agent

  • MLP Link Predictor — binary edge score per part pair
  • Threshold → missing component candidates
  • AIDA (Gemini 2.5 Flash) — 6 domain skills, natural-language explanations
  • Missing components visualised in the 3D viewer — predicted gaps rendered in a distinct mesh colour (lime green) with colour-coded legends distinguishing present, missing, and flagged parts
AIDA Skills Agent:  Gemini 2.5 Flash + engineering_3d_assembly.yaml persona → assembly-category analysis · joint-type identification · corrective suggestions · 6 domain skills total
