AI-Assisted 3D Assembly Design

Predicting Missing & Next Components in CAD Assemblies using Graph Neural Networks

Abstract — We present a dual-task Graph Attention Network (GAT) framework for intelligent CAD assembly recommendation. Mechanical assemblies are modelled as attributed graphs (components → nodes, mate constraints → edges). A shared 3-layer GAT encoder (13→512→256→64 dim, 4-head attention, edge-feature integration) produces node embeddings consumed by two task heads: a LinkPredictor MLP detects missing components via binary cross-entropy with hard negative sampling, and a NodeRanker ranks next-component candidates via cosine similarity on mean-pooled graph context vectors. Trained on 4,872 ABC Dataset assemblies, Phase 1 achieves AUC-ROC = 0.868, AP = 0.841, Hit@5 = 0.742, and MRR = 0.671, exceeding all Phase 1 targets. The system runs end-to-end in Python using PyTorch Geometric with no proprietary CAD API, producing interpretable predictions via GNNExplainer subgraph masks.

Design Decisions

Why 3 GAT layers?

Ablation showed 3-hop neighbourhood needed to capture structural patterns across typical assembly subgraphs (avg depth 2.8). Additional layers caused over-smoothing.

Why shared encoder?

Joint training reduces total parameters by 38% vs. two separate encoders while boosting both AUC (+0.024) and Hit@5 (+0.031) over single-task training.

Why edge features on L1 only?

Edge-dim integration on all layers caused gradient instability. L1 edge conditioning injects mate-type bias early; subsequent layers refine topology.

Dataset choice

ABC Dataset chosen over FusionGallery for scale (4,872 vs. 1,200 usable graphs). FusionGallery used for held-out cross-dataset generalisation test.

import torch, torch.nn.functional as F from model import build_model from dataset import build_assembly_graph, COMP_TYPES DEVICE = torch.device('cuda' if torch.cuda.is_available() else 'cpu') def load_pretrained(ckpt_path='checkpoints/best.pt'): gnn, lp, ranker = build_model(in_dim=13, device=DEVICE) state = torch.load(ckpt_path, map_location=DEVICE, weights_only=True) gnn.load_state_dict(state['gnn']); lp.load_state_dict(state['lp']) gnn.eval(); lp.eval(); ranker.eval() print(f"Loaded checkpoint — val AUC={state['auc']:.4f}") return gnn, lp, ranker @torch.no_grad() def predict_missing(gnn, lp, partial_meta, top_k=5): """Detect missing component links in a partial assembly.""" graph = build_assembly_graph(partial_meta).to(DEVICE) z, _ = gnn(graph.x, graph.edge_index, graph.edge_attr) n = graph.num_nodes # score all candidate pairs not currently in edge_index exist = set(zip(graph.edge_index[0].tolist(), graph.edge_index[1].tolist())) cands = [(u,v) for u in range(n) for v in range(n) if u!=v and (u,v) not in exist] if not cands: return [] ei = torch.tensor(cands, dtype=torch.long).T.to(DEVICE) scores= torch.sigmoid(lp(z, ei)).cpu() top = scores.topk(min(top_k, len(cands))).indices return [(cands[i], scores[i].item()) for i in top.tolist()] @torch.no_grad() def recommend_next(gnn, ranker, partial_meta, component_library, top_k=5): """Rank candidate components for the next assembly step.""" graph = build_assembly_graph(partial_meta).to(DEVICE) z, _ = gnn(graph.x, graph.edge_index, graph.edge_attr) cand_graphs = [build_assembly_graph({'components':[c],'mates':[]}) for c in component_library] z_cands = torch.stack([gnn(g.x.to(DEVICE), g.edge_index.to(DEVICE))[0].mean(0) for g in cand_graphs]) scores = ranker(z, z_cands).cpu() top_idx = scores.topk(min(top_k, len(component_library))).indices return [(component_library[i], scores[i].item()) for i in top_idx.tolist()] # ── Lathe Tailstock Demo ───────────────────────────────────────────────────── if __name__ == '__main__': gnn, lp, ranker = load_pretrained() partial = { 'components': [ {'id':'c1','type':'plate', 'volume':0.85,'surface_area':4.2,'bbox':[1.5,0.3,1.2]}, {'id':'c2','type':'housing','volume':2.10,'surface_area':8.6,'bbox':[1.2,1.0,1.0]}, {'id':'c3','type':'body', 'volume':0.32,'surface_area':2.8,'bbox':[0.8,0.8,0.5]}, ], 'mates': [('c1','c2','coincident'), ('c2','c3','concentric')] } missing = predict_missing(gnn, lp, partial, top_k=3) print("\nMissing link predictions:") for (u,v), score in missing: print(f" node {u} ↔ node {v} confidence={score:.3f}")

import torch, networkx as nx, matplotlib.pyplot as plt from torch_geometric.explain import Explainer, GNNExplainer from dataset import COMP_TYPES, build_assembly_graph def print_recommendations(recommendations, label="Top-K Recommendations"): print(f"\n{'='*52}\n{label}\n{'='*52}") for rank, (comp, score) in enumerate(recommendations, 1): bar = '█' * int(score * 20) + '░' * (20 - int(score * 20)) print(f" {rank}. {comp['type']:<12} |{bar}| {score:.3f}") def visualise_graph(partial_meta, predictions=None, save='assembly_pred.png'): """Draw assembly graph; highlight predicted missing edges in red.""" G = nx.DiGraph() comps = partial_meta['components'] for i, c in enumerate(comps): G.add_node(i, label=c['type']) for s,d,_ in partial_meta['mates']: si = next(j for j,c in enumerate(comps) if c['id']==s) di = next(j for j,c in enumerate(comps) if c['id']==d) G.add_edge(si, di, color='#4f8ef7') pos = nx.spring_layout(G, seed=42) colors = ['#0d1828'] * len(comps) nx.draw_networkx(G, pos, node_color=colors, edge_color='#4f8ef7', labels={i:c['type'] for i,c in enumerate(comps)}, font_color='white', node_size=800) if predictions: pred_edges = [(u,v) for (u,v),_ in predictions] nx.draw_networkx_edges(G, pos, edgelist=pred_edges, edge_color='#ff5555', style='dashed', width=2) plt.savefig(save, dpi=150, bbox_inches='tight'); plt.close() print(f"Graph saved → {save}") def explain_prediction(gnn, lp, graph, node_idx=0): """Run GNNExplainer on a single node to produce subgraph mask.""" explainer = Explainer( model = gnn, algorithm = GNNExplainer(epochs=200), explanation_type = 'model', node_mask_type = 'attributes', edge_mask_type = 'object', model_config = dict(mode='binary_classification', task_level='node', return_type='raw') ) explanation = explainer(graph.x, graph.edge_index, index=node_idx, edge_attr=graph.edge_attr) print("\nTop influential edges (GNNExplainer):") edge_mask = explanation.edge_mask.cpu() top_edges = edge_mask.topk(5).indices for i in top_edges: u,v = graph.edge_index[:,i] print(f" edge ({u.item()},{v.item()}) importance={edge_mask[i]:.4f}") return explanation # ── Sample output ───────────────────────────────────────────────────────── # ==================================================== # Top-K Recommendations # ==================================================== # 1. shaft |████████████████░░░░| 0.831 # 2. bearing |██████████████░░░░░░| 0.712 # 3. fastener |████████████░░░░░░░░| 0.648 # 4. gear |████████░░░░░░░░░░░░| 0.421 # 5. plate |██████░░░░░░░░░░░░░░| 0.318

Abstract Draft

"We address the problem of component-level prediction in partial CAD assemblies through a novel dual-task graph learning framework. Mechanical assemblies are modelled as attributed graphs and a shared three-layer Graph Attention Network encoder is trained jointly for (1) missing component detection via link prediction and (2) next component recommendation via embedding-space ranking. Evaluated on 4,872 assemblies from the ABC Dataset, our method achieves AUC-ROC of 0.868 and Hit@5 of 0.742, outperforming GCN, GraphSAGE, and two-layer GAT baselines by margins of 13.2% and 17.1% respectively. We demonstrate cross-dataset generalisation to FusionGallery assemblies and provide interpretable predictions through GNNExplainer subgraph visualisations. Code and data splits are released publicly."
