Title & Abstract

Project Title

AI-Assisted 3D Assembly Design: Predicting Missing Components in CAD Assemblies using Graph Neural Networks

Abstract

Engineering CAD assemblies consist of multiple interconnected components whose correct selection is time-consuming and expertise-dependent. This project trains a Graph Attention Network (GAT) on assembly graphs to detect missing components via link prediction.

A Gemini-powered Skills AI agent (AIDA) explains predictions in engineering language. An Assembly Completeness Model learns per-category component-type distributions and identifies what is missing from partial or single-component uploads.

An Octree-based Open Surface Detector (inspired by Borah & Borah 2020) identifies the precise mesh surfaces where missing components should be assembled, highlighting them in lime green directly on the 3D model.

The solution is implemented entirely in Python using PyTorch Geometric, without dependency on proprietary CAD software APIs.

Key Contributions

  • GNN-based link prediction for missing component detection in 3D assemblies
  • 22-dim node + 6-dim edge features — geometry-driven SDF, affine-invariant shape descriptors, hole counts, joint types
  • Assembly Completeness Model — template-based gap analysis per assembly category
  • Octree open surface detection — spatial localisation of unmated joints
  • AIDA — Gemini AI agent for engineering-language explanations
  • End-to-end Streamlit app — interactive 3D viewer with dual-panel analysis

Key Improvements over R14 → R15

  • P1: GAT heads widened to [8, 4, 1] — richer multi-head attention
  • P2: 18-dim affine-invariant features replace rotation-sensitive bbox deltas
  • P3: Structured synthetic bolt/shaft/mixed templates
  • P4: Hard-negative sampling (0.3× BCE weight)
  • P5: neg_ratio halved to 0.5
  • P6: Mean AUC +10 points (0.624 → 0.726)
