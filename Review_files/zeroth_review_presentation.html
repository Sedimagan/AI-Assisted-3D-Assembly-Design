AI-Assisted 3D Assembly Design
Predicting Missing & Next Components in CAD Assemblies using Graph Neural Networks
Problem Context

Engineering Challenge

Modern CAD assemblies contain 50–500+ interconnected components. Engineers manually search part libraries, relying entirely on domain experience — a process that is slow, inconsistent, and error-prone.

Pain Points
  • Knowledge barrier: Junior engineers lack contextual assembly experience built over years.
  • No automation: Existing CAD tools (SolidWorks, CATIA) offer no intelligent part suggestion during assembly creation.
  • Non-standardisation: Different designers make inconsistent choices for equivalent subassemblies.
  • Incomplete assemblies: Partially defined assemblies have no automated mechanism to detect or fill missing parts.
Research Gap: No existing system applies graph-based deep learning to recommend components from partial CAD assembly graphs without proprietary API dependency. This project fills that gap using Graph Neural Networks trained on open CAD datasets.
Visual Concept
Research Objectives
  • Model assemblies as attributed graphs
  • Train GNN for link prediction (missing parts)
  • Build top-K ranking for next-component suggestion
  • Provide GNNExplainer interpretability
  • Pure Python — no proprietary CAD API

Data Sources

① ABC Dataset  Koch et al., CVPR 2019

1 million+ open-source CAD models in STEP / B-Rep format. Contains geometric metadata: bounding boxes, volumes, surface areas, mate constraints between components.

1M+ STEP files B-Rep format Geometry metadata Open licence

② PartNet  Mo et al., CVPR 2019

573,585 part instances across 26 categories with fine-grained, hierarchical part-level annotations. Provides assembly-level semantics (parent–child relationships) critical for edge-feature construction.

573K annotated parts 26 categories Hierarchical labels

③ FusionGallery  Willis et al., 2021

8,625 multi-body Fusion 360 assemblies with native mate-constraint graphs, providing direct edge supervision for training the link prediction head.

8.6K assemblies Native mate graph Direct edge labels

④ Synthetic Partial Graphs

Generated by masking 20–40 % of edges/nodes from complete training graphs. Used to simulate partially defined assemblies for evaluation.

Feasibility Study

Technical Feasibility

  • Open data: ABC + PartNet freely available; no procurement needed.
  • Mature framework: PyTorch Geometric v2.x supports GAT, GraphSAGE, link prediction, GNNExplainer out-of-the-box.
  • No CAD API: Graph construction from metadata JSON / STEP parser avoids proprietary licences.
  • Compute: Google Colab Pro (A100) or university GPU cluster sufficient for dataset scale.

AI Tasks Involved

This project maps to standard AI task paradigms:

🔗

Link Prediction

Detect missing edges (mates) and nodes (components) in partial assembly graphs.

→ Analogous to Fraud Detection in transaction networks
🏷️

Node Classification & Ranking

Classify candidate components and rank them by fitness for the current partial assembly context.

→ Analogous to Image Recognition / Object Segmentation
📊

Graph-Level Pattern Learning

Learn structural patterns from complete assembly graphs to guide predictions on unseen partials.

→ Analogous to Sentiment Analysis — learning context from sequence
🧩

Sub-graph Completion

Reconstruct missing subgraph regions — components and their constraint edges — as a coherent unit.

→ Analogous to Object Segmentation / Inpainting in vision
Algorithms to Explore

GCN

Spectral baseline. Symmetric adjacency normalisation. Fast convergence.

GAT ★

Attention per edge. Multi-head (4 heads). Built-in interpretability.

GraphSAGE

Inductive sampling. Handles unseen component types at inference.

HetGNN

Heterogeneous node / edge types. Richer CAD semantics. Phase 2.

Graph VAE

Variational autoencoder for probabilistic link scoring. AUC baseline.

GNNExplainer

Post-hoc subgraph masks. Attention visualisation. Interpretability.

Architecture: Shared GAT encoder → dual task heads: LinkPredictor (MLP on hu‖hv) & NodeRanker (cosine sim on mean-pooled context).

Training Strategy

  • Loss: Binary cross-entropy with negative sampling (1:1 pos/neg)
  • Optimiser: Adam — lr=1e-3, weight decay=5e-4
  • Epochs: 200 with early stopping (patience=20)
