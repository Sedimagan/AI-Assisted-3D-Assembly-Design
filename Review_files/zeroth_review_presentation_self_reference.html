AI-Assisted 3D Assembly Design

Predicting Missing & Next Components in CAD Assemblies using Graph Neural Networks

Abstract — Engineering CAD assemblies consist of multiple interconnected components whose correct selection is time-consuming and expertise-dependent. This project proposes an intelligent recommendation system that models assemblies as graphs — components as nodes, relationships as edges — and trains a Graph Neural Network (GNN) on historical assembly data to learn structural patterns. The trained model predicts missing components and suggests the most suitable next component for a partially defined assembly, outputting ranked top-K recommendations with model-level interpretability. The solution is implemented entirely in Python using PyTorch Geometric, without dependency on proprietary CAD software APIs.

Background & Problem

Modern CAD tools — SolidWorks, CATIA, Fusion 360 — support parametric modelling but offer no contextual intelligence during assembly creation. Engineers rely entirely on domain knowledge to choose and position each component.

  • Time-intensive: Selecting correct parts in complex assemblies (100+ components) can take hours of lookup and trial.
  • Error-prone: Wrong part choices propagate downstream — rework, redesign, and increased cost.
  • Non-standardised: Different designers make different choices for equivalent assemblies, reducing consistency.
  • Knowledge barrier: Junior engineers lack the assembly patterns that experienced engineers build over years.

Research Objectives

  1. Model CAD assemblies as graphs — Represent components as feature-rich nodes and assembly constraints as typed edges using open datasets.
  2. Train a GNN for link prediction — Learn structural patterns from complete assembly graphs to detect missing components in partial inputs.
  3. Build a component recommendation engine — Rank top-K candidate parts for the next assembly step using learned graph embeddings.
  4. Provide interpretability — Explain recommendations via GNN attention weights and subgraph explanations (GNNExplainer).
  5. Python-only implementation — No dependency on proprietary CAD APIs; reproducible with open-source tools.

Literature Survey

Graph Neural Networks — Fundamentals & Architectures

Key papers: Kipf & Welling (2017) — GCN  ·  Veličković et al. (2018) — GAT  ·  Hamilton et al. (2017) — GraphSAGE

GNNs extend deep learning to graph-structured data through message passing — each node aggregates features from its neighbours over multiple layers to build rich contextual embeddings. GCN uses symmetric normalisation; GAT introduces learnable per-edge attention; GraphSAGE enables inductive learning on unseen nodes. These three form the backbone architecture candidates for this project.

Link Prediction using Graph Neural Networks

Key papers: Zhang & Chen (2018) — SEAL  ·  Kipf & Welling (2016) — Graph Autoencoders  ·  Cai et al. (2021) survey

Link prediction infers missing or future edges in a graph — directly mapping to the missing component detection task. Graph Autoencoder (GAE) encodes nodes into latent space and decodes edge probabilities; SEAL extracts local enclosing subgraphs for each candidate pair. Negative sampling strategies (random vs. hard negatives) critically affect model quality and will be studied during Phase 1 replication.

Literature Survey (cont.)

3

CAD Assembly Representation as Graphs

Key papers: Koch et al. (2019) — ABC Dataset  ·  Mo et al. (2019) — PartNet  ·  Jayaraman et al. (2021) — UV-Net on B-Rep

CAD assemblies are natively tree- or graph-structured: components (solid bodies) are nodes; mating constraints (coincident, parallel, concentric) are edges. The ABC Dataset provides 1M+ CAD models in STEP format; PartNet offers hierarchical part-level annotations. Understanding BRep-to-graph conversion — node features (volume, surface area, type), edge features (mate type, DOF) — is the essential data-engineering step for Phase 1.

4

Assembly Design Automation & Part Recommendation

Key papers: Sung et al. (2017) — ComplementMe  ·  Jones et al. (2021) — ShapeAssembly  ·  Shi et al. (2023) — GNN for assembly sequence

Prior work uses shape embeddings and retrieval to suggest complementary parts (ComplementMe); ShapeAssembly uses a domain-specific language to generate assembly programs. More recent work applies GNNs to predict assembly sequences from complete graphs. This project extends these ideas to partial graphs — recommending the next node given an incomplete assembly — the key novelty to be developed in Phase 2.

Proposed System

System Architecture

  1. Data Ingestion & Graph Construction
    Parse ABC / PartNet STEP files → extract components as nodes (type, volume, surface features) and mates as edges (constraint type, DOF).
  2. GNN Encoder
    Stack of GAT / GraphSAGE layers. Each layer aggregates neighbour messages → produces contextual node embedding hv.
  3. Task Head A — Link Prediction
    Score function on node-pair embeddings (dot product / MLP). Identifies missing components in partial assembly graphs.
  4. Task Head B — Node Ranking
    Embed candidate components; cosine similarity against current partial-graph embedding → ranked top-K suggestions.
  5. Interpretability Layer
    GNNExplainer identifies the minimal subgraph that justifies each prediction; attention maps highlight influential neighbours.
