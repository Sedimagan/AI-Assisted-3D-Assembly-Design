🧩 Unused Features in Your JSON (free signal)

🕳
Hole count — strongest missing node feature
64.6% of assemblies have hole data. A body with N holes is almost certainly an attachment point for N fasteners. Adding log1p(n_holes) as dim-22 costs nothing — data is already parsed. 25.5% of assemblies have 10+ holes (high fastener density).
ADD TO DATASET.PY
⚙
Joint type — strongest missing edge feature
2,230 joints annotated across 430 assemblies. Joint-to-contact ratio = 0.38 (38 joints per 100 contacts on average). A 4-dim one-hot [rigid, revolute, slider, cylindrical] on edges would give GAT motion-aware signals — rigid vs revolute is a fundamentally different assembly relationship.
ADD TO DATASET.PY
🎨
Material — already partially used, but coarse
Steel = 79.9% of all bodies. Current type one-hot doesn't encode material. Adding a 3-dim material group [steel, aluminium, plastic/other] as extra node dims would help distinguish corrosion-resistant vs structural parts — Stainless Steel rarely connects to ABS Plastic.
