💡 Key Insights & Recommendations

✓ node filter is perfect. max_nodes=20 keeps 100% of assemblies. P99=19. No data lost.
✗ Pre-filter 641 zero-contact assemblies before STEP parsing. Free 28% speedup — these can never form graph edges. Add: if len(d.get("contacts",{})) == 0: skip
⚠ Class imbalance: Mech. Eng. = 80%. Consider weighted sampling or per-category train split to stop model over-specialising on Mech. Eng. patterns.
💡 Add hole count as node feature. 64.6% of assemblies have hole data. log1p(n_holes) per body = strong fastener signal — bodies with many holes are attachment points. Free +1 dim.
💡 Add joint_type as edge feature. 2,230 joints annotated. 4-dim one-hot [rigid, revolute, slider, cylindrical] gives GAT motion-aware edge signals. Currently unused.
